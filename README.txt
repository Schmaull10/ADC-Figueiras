ADC FIGUEIRAS · TEAM MANAGER — V1 (PWA)

O que inclui
- Dashboard da equipa
- Plantel e disponibilidade
- Treinos, presenças e pesagens antes/depois
- Jogos, convocatórias, resultados e estatísticas individuais
- Calendário mensal
- Multas e estado de pagamento
- Exportação/importação de backup JSON
- Layout responsivo para PC e telemóvel
- Emblema oficial do ADC Figueiras

COMO ABRIR NO COMPUTADOR
1. Faz duplo clique em index.html.
2. A aplicação funciona diretamente no browser e guarda os dados localmente nesse browser/dispositivo.

COMO USAR NO TELEMÓVEL “TIPO APP”
Opção recomendada: publicar estes ficheiros num alojamento simples HTTPS (por exemplo GitHub Pages, Netlify ou Vercel).
Depois:
- Android/Chrome: abrir o link e escolher “Adicionar ao ecrã principal” ou “Instalar aplicação”.
- iPhone/Safari: abrir o link, tocar em Partilhar e escolher “Adicionar ao ecrã principal”.

IMPORTANTE
- Nesta V1 não existe servidor nem sincronização entre vários telemóveis/computadores.
- Cada dispositivo guarda os seus próprios dados.
- Usa Definições > Exportar dados para guardar cópias de segurança.
- A abertura direta do index.html continua funcional, mas a instalação como app/PWA fica limitada se usares file:// em vez de HTTP/HTTPS.
